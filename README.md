# Monte Trip 2028

Gestão da viagem de formatura do 3º ano do Colégio Monte.

Site: https://diogo-nobrega7.github.io/monte-trip-2028/ (login da administração em `#entrar`)

```
npm install
npm run dev
npm test                 # cálculos
scripts/db-test.sh       # banco e permissões (Postgres local; ver o arquivo)
```

Gestão completa: configurações com aprovação do professor, mensalidades com atraso e pagamento parcial,
arrecadações, despesas com comprovante, documentos, agências, prestação de contas (CSV/PDF), importação e backup.
